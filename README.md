# CLIP AI Studio — Premium Violet · By Senya

Локальное приложение для подготовки коротких видео, субтитров и Twitch-хайлайтов. Текущая передаваемая версия исходника — **v21 (Twitch Clipper)**.

## Что внутри

- `app.py` — основной исходный код приложения.
- `requirements.txt` — Python-зависимости.
- `START_CLIP_AI.bat` — установка окружения и запуск на Windows 10/11.
- `AI_CONTEXT.md` — подробная передача контекста следующему ChatGPT/разработчику.
- `.gitignore` — не даёт случайно отправить локальные видео, проекты и секреты в GitHub.
- `data/`, `uploads/`, `outputs/` — пустые папки-хранилища; реальные данные остаются локальными.

## Запуск на Windows

1. Установить **Python 3.11 x64** с https://www.python.org/downloads/ (включить Python Launcher / Add Python to PATH).
2. Скачать репозиторий ZIP-архивом или выполнить `git clone`.
3. Открыть папку проекта.
4. Дважды нажать `START_CLIP_AI.bat`.
5. При первом запуске скрипт создаст `.venv`, установит зависимости и запустит Streamlit.
6. Открыть `http://localhost:8501`, если браузер не открылся автоматически.

Первый запуск может занять несколько минут: зависимости и модель распознавания речи загружаются из интернета. Окно командной строки нужно оставить открытым. Чтобы остановить приложение, нажать `Ctrl+C` в этом окне.

## Запуск на macOS / Linux

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

## Это локальный сайт или публичный сайт?

Сейчас это **локальное веб-приложение**: Python/Streamlit работает на компьютере пользователя, а браузер показывает интерфейс через `localhost`. Само приложение не опубликовано в интернете. GitHub хранит исходный код и историю изменений, но не запускает этот Streamlit-сервис автоматически.

Другой человек может клонировать репозиторий и запустить свою локальную копию. Его проекты, загрузки, клипы, настройки и токены будут отдельными от твоих, если не переносить данные вручную. Для общей онлайн-версии понадобится отдельный хостинг/сервер и отдельная настройка хранения файлов, секретов и пользователей.

## Локальные данные

Приложение создаёт и использует:

- `uploads/` — загруженные исходные файлы;
- `outputs/` — экспортированные клипы и результаты;
- `data/projects/` — проекты;
- `data/calendar.json`, `data/ad_drafts.json`, `data/creation_templates.json` — локальные данные соответствующих модулей;
- `data/twitch_clipper/live_logs/` — LIVE-логи Twitch;
- `data/twitch_clipper/sessions/` — метаданные сессий Twitch Clipper.

Эти данные намеренно исключены из Git через `.gitignore`. Если нужно перенести проекты на другой компьютер, останови приложение и скопируй нужные папки `data/`, `uploads/` и `outputs/` отдельно. Не загружай туда чужие/конфиденциальные видео без разрешения.

## Секреты и безопасность

Не добавляй в GitHub OpenAI API keys, Twitch OAuth tokens, пароли, `.env`, `.streamlit/secrets.toml`, личные видео и логи. Если секрет случайно попал в публичный репозиторий — отзови/перевыпусти его в соответствующем сервисе; простого удаления коммита недостаточно.

Для Twitch LIVE требуется OAuth access token с `chat:read`; встроенное создание Twitch Clip требует также `clips:edit` и совпадающий Twitch Client ID. Текущая версия не отправляет сообщения в чат. Токены вводятся в интерфейсе и не должны попадать в скриншоты или GitHub.

Для OpenAI-функций нужен отдельный API key и доступ/оплата API. Подписка ChatGPT сама по себе не включает API-баланс.

## Ограничения текущего Twitch Clipper

- LIVE-режим читает чат, сохраняет таймкоды и определяет всплески активности. Он **не записывает видео стрима**.
- Чтобы получить MP4 после эфира, нужен соответствующий VOD/локальная запись и чат-лог с таймкодами от начала именно этого VOD.
- VOD-режим принимает экспорт TwitchDownloader (JSON/JSON.GZ), JSONL, CSV, TXT или SRT и вырезает MP4-моменты по активности чата.
- Прямой бесконечный live-поток не является VOD; для LIVE используйте мониторинг чата, а видео обработайте после появления записи.
- Доступность Twitch VOD зависит от настроек канала, приватности, региона и правил платформы.

## Работа вдвоём через GitHub

1. Один человек создаёт репозиторий и загружает в него файлы этого комплекта.
2. В GitHub: **Settings → Collaborators** (или Collaborators and teams) → пригласить брата по GitHub username.
3. Брат принимает приглашение, клонирует репозиторий и запускает `START_CLIP_AI.bat`.
4. Для изменений он создаёт отдельную ветку, коммитит изменения и открывает Pull Request.
5. Перед слиянием проверяйте изменения и не добавляйте в коммиты локальные данные или секреты.

Подробный контекст проекта и инструкция для следующего ChatGPT находятся в [`AI_CONTEXT.md`](AI_CONTEXT.md).
